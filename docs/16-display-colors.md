# ST7789 面板反色修复

2026-11-18 安卓恢复测试期间，用户报告正常状态条为紫色。
进一步观察为白底深色字、告警条蓝色/青色，符合整体负色的表现。
BLE ACK `OK 6`、`OK 1` 均已收到，接收路径不作为此次修复对象。

## 定位

状态颜色在 `ui_render_nav()` 中为正常 `0x00B000`、偏航 `0xD00000`。
当前 LVGL 为 RGB565、`LV_COLOR_16_SWAP=1`，驱动原样发送缓冲。
主机颜色探针实际生成的 SPI 字节：

| RGB 输入 | 字节 |
|---|---|
| 黑 000000 | 00 00 |
| 白 FFFFFF | FF FF |
| 正常绿 00B000 | 05 80 |
| 告警红 D00000 | D0 00 |
| 转向青 00E5FF | 07 3F |

字节顺序正确。初始化此前无条件发送 INVON（0x21），
现在由 `ST7789_INVERSION_ON` 控制，针对本面板默认发送 INVOFF（0x20）。
不同时改 RGB/BGR、LVGL 字节交换或调色值，以便单独验证反色设置。
命令定义见 [ST7789V 数据手册](https://dl.espressif.com/dl/schematics/ST7789V_SPEC_V1.0.pdf)。

其他屏幕型号可能需要不同反色极性；本默认值仅依据当前实物观察，
不能把当前面板配置直接套用到所有 ST7789 模组。

## 验证

构建 BLE 版，烧录后重新发送手机正常帧，应呈黑底、白字、绿色状态条。
再发送偏航帧确认红色；停发后的 signal lost 也应为红色状态条。
本轮不以 UART ACK 通过替代视觉颜色验收。
旧固件保存在本机 `firmware/build_baseline/app_ble_before_color_fix.elf`。
