# 调试日志

> 规则：**只记你自己踩的坑**。参考文档里的"已知坑"是别人的，面试时讲不深。
> 每天收尾花 3 行，比事后回忆两小时有用。
> 这份文件是你面试时"遇到过什么困难、怎么定位"的唯一素材来源，不要写作文。

---

## 格式

```
## MM-DD  一句话现象
试了：具体动作 → 结果
结论：根因（一句话），写进/改进了哪个文件
下次：如果再来一次，我会先查什么
```
