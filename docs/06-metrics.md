## 5. 填表纪律

1. 同一指标至少测 3 次，记均值和最差；
2. 每条都要能说出**仪器型号 + 接入点 + 判据**；
3. 改动硬件（换线、换频）后旧数据作废，重测或标注条件。

## 6. M5 本次测量（2026-11-18，单次验收，不是多次均值）

硬件 NUCLEO-F446RE，ST-Link V2，USART2 VCP 115200 8N1。
FreeRTOS V11.1.0、LVGL 8.3.11，Arm GCC 14.3.1、`-Os`。
历史 M4 表格保留用于追溯，不与本表混用。

| 指标 | 本次结果 | 方法与边界 |
|---|---|---|
| Flash 区域使用 | 267,040 B / 512 KiB（50.93%） | GNU ld 区域使用，含对齐间隙 |
| 静态 RAM 区域使用 | 69,360 B / 128 KiB（52.92%） | 含静态任务栈、LVGL 池、链接脚本预留区 |
| FreeRTOS 动态堆 | 未启用 | 所有任务及队列静态分配；LVGL 内存池单独保留 |
| 三任务最小栈余量（短测） | comms 1824 B / ui 6556 B / mon 1924 B | uxTaskGetStackHighWaterMark，换算字节，经 ST-Link 热连接读取 |
| UI 停滞复位 | 启动计数 7 → 8 | 自测版仅挂起 UI，监控停止喂狗；未测精确复位延时 |
| 初次持续收帧 | 3000/3000，序号顺序一致 | 648.485 秒，实际约 4.63Hz；PC 定时漂移，不能标成严格 5Hz |
| 动态画面短测 | 300/300，全项通过 | 60.313 秒（含末尾 0.3 秒收尾窗口），修正为绝对节拍；用户确认画面正常变化 |
| 最终动态长测 | 3000/3000，600.313 秒，约 5Hz | 确认顺序一致，全部错误恢复检查通过；含 0.3 秒收尾窗口，计算速率 4.997Hz |
| 长测复位与接收错误 | 启动计数 9 → 9，溢出 0，UART 错误 0 | ST-Link 热连接读取前后计数，正常固件期间未发生计数复位 |
| 最终三任务最小栈余量 | comms 1824 B / ui 6556 B / mon 1884 B | 覆盖上述动态长测与错误恢复路径 |
