# 演示脚本（拍 45 秒视频用）

> 目标：45 秒内让人相信"这玩意是真的，而且他想清楚了"。
> 面试时把视频存在手机里，聊到项目直接放。**别在面试现场折腾接线**。
>
> 拍摄要点：手机横屏、固定机位（用书立起来）、桌面只留板子/屏/一根 USB 线、灯光从侧面打。
> **全程不要拍到嘴和脸**，只拍手 + 屏幕。

---

## 一、拍之前准备（5 分钟）

| 步骤 | 命令 / 动作 |
|---|---|
| 1 | 板子接 USB，屏幕已按 `docs/wiring-diagram.svg` 接好 |
| 2 | 确认屏幕正常：烧录后应显示 LVGL 界面（转向符号 + `--`） |
| 3 | 装好 pyserial：`pip install pyserial` |
| 4 | 确认串口号：设备管理器 → `STLink Virtual COM Port (COMxx)` |
| 5 | 电脑上开两个窗口并排：**终端**（跑命令）+ **GitHub 仓库页** |
| 6 | 手机开录屏/录像，先拍 1 秒空镜，再开始 |

> 建议录两遍：第一遍练手，第二遍正式。**不要一条过**，剪辑比反复重录省时间。

---

## 二、分镜脚本

### 镜头 1（0–5s）· 硬件全景
**画面**：拉近板子 + 屏幕，能看清排线。
**字幕**：`STM32F446RE + ST7789 240×320 SPI 屏`
**旁白（可选）**：这是我的骑行导航 HUD 原型，手机或上位机发数据，单片机解析后显示转向和距离。

---

### 镜头 2（5–20s）· 实时数据驱动 ★最关键
**画面**：屏幕特写 + 终端窗口同框。

**终端执行**：

```powershell
python tools\sim_sender.py --port COM13 --baud 115200 --hz 5
```

**屏幕上应该看到**：
- 转向符号在变：↑ 直行 → → 右转 → ← 左转 → ↻ 掉头 → ✔ 到达
- 距离数字快速递减：`800 → 700 → 600 …`
- 底部小字：`45 km/h  12.4 km  18 min`
- 底部状态条：绿色

**字幕**：`PC 5Hz 发送 16 字节定长帧 → 解析 → 实时刷新`

**旁白**：帧率 5Hz，也就是每 200ms 一帧，屏幕跟得上。

---

### 镜头 3（20–30s）· 断连检测 ★差异化
**动作**：`Ctrl+C` 停止发送，**手指指向屏幕**。

**3 秒后屏幕应该变成**：
- 警告图标 + `--`
- 底部文字变 `signal lost`
- 状态条变**红色**

**字幕**：`停止发送 3 秒 → 自动判定断连并置灰，不显示过期数据`

**旁白**：这是我自己定的规则：3 秒没有有效帧就认为链路断了，恢复要连续 2 帧才算重连，避免抖动。

---

### 镜头 4（30–38s）· 健壮性 ★最加分
**终端执行**：

```powershell
python tools\sim_sender.py --port COM13 --baud 115200 --hz 5 --fault badcrc --seconds 12 --log
```

**画面**：滚动输出里能看出 `OK 46`、`OK 47`……中间**跳过**几个序号。

**字幕**：`每 10 帧注入 1 帧错 CRC —— 只丢这一帧，后面的帧照常解析`

**旁白**：这是我最花心思的地方。CRC 校验失败时我只回退一个字节重新找帧头，而不是清空缓冲区——清空会把后面已经收到的好帧一起丢掉。

---

### 镜头 5（38–45s）· 工程化收尾
**画面**：切到终端跑单元测试 + GitHub 页面。

```powershell
.\tests\run.ps1
```

**输出最后一行**：`ALL PASS (96 checks)`

**然后**切到浏览器：仓库页面，快速滑过 `docs/` 目录（让别人看到有文档）。

**字幕**：`96 项宿主机单元测试 · 协议与硬件解耦 · 文档与实测数据全部开源`

## 四、剪辑与发布

1. **剪到 45 秒以内**，超过 1 分钟没人看完。
2. 加**字幕**（不靠旁白也能看懂），字号大一点。
3. 导出 1080p、码率中等即可，控制在 **20MB 以内**，方便微信发。
4. 文件名：`MotoNavHUD-demo-45s.mp4`
5. 同时**存一份到 GitHub 仓库的 Releases**（打 tag `v1.0` 时上传），简历里就能直接放链接。

## 五、常见翻车点

| 问题 | 预防 |
|---|---|
| 屏幕反光看不清 | 灯光打侧面、别用顶灯直射 |
| 手机对焦来回跳 | 先点屏幕对焦锁定，再开录 |
| 距离数字变小太快看不清 | 加 `--hz 2` 放慢到 2Hz |
| 断连镜头等待太久 | 提前算好：停止后数 1-2-3 就变 |
| 终端字体太小 | Ctrl+滚轮放大到 20 号以上 |
| COM 口号不对 | 提前确认，别在录的时候试 |

## 六、一句话记住
